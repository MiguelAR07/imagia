# Marca IMAGIA

**Imagina + Magia + IA.** Lema: _Tú lo imaginas. Nosotros hacemos la magia._

| Letra | Palabra          | Qué representa                                          |
| ----- | ---------------- | ------------------------------------------------------- |
| I     | Innovación       | Ideas nuevas convertidas en productos que generan valor |
| M     | Movilidad        | Apps para celular                                       |
| A     | Automatización   | Procesos que funcionan solos                            |
| G     | Gestión          | Sistemas y paneles administrativos                      |
| I     | Inteligencia     | IA aplicada                                             |
| A     | Aplicaciones web | Webs, landing pages y plataformas                       |

## Archivos

| Archivo                     | Uso                                                                                                      |
| --------------------------- | -------------------------------------------------------------------------------------------------------- |
| `imagia-isotipo.svg`        | Símbolo para fondos oscuros                                                                              |
| `imagia-isotipo-claro.svg`  | Símbolo para fondos claros (documentos, PDF)                                                             |
| `imagia-isotipo-blanco.svg` | Símbolo a una tinta, sobre color de marca o fotos                                                        |
| `imagia-horizontal.svg`     | Firma horizontal (símbolo + nombre + descriptor) para fondo oscuro                                       |
| `favicon.svg`               | Pestaña del navegador e ícono de app                                                                     |
| `brand.json`                | Nombre, siglas, lema, colores y tipografías. La plataforma lo usa como configuración inicial de la marca |

## Reglas rápidas

- El nombre se escribe en mayúsculas: **IMAGIA**. Las letras **IA** van en el degradado azul → cian.
- Área de respeto: dejar libre alrededor del logo al menos la altura del cuadrado interior.
- Tamaño mínimo del símbolo: 16 px (usar `favicon.svg`, que tiene trazos más gruesos).
- `imagia-horizontal.svg` usa fuentes de Google Fonts. Antes de enviarlo a una imprenta hay que convertir los textos a trazos.
- Dominio y registro de marca: **pendiente de verificar**.
